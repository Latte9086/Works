# ことばの栞

`dist/index.html` をブラウザーで開くと利用できます。APIキー・ビルド不要の静的アプリです。用途選択から小説翻訳・肌分析と、それぞれの初心者・中級者・上級者ページへ移動します。

英語力、使用AI、解説量、学習の重点、類似表現・練習・カードの有無を選ぶと、用意済みのテンプレートからプロンプトを生成します。AI自体の呼び出しは行いません。英文と背景は保存しません。設定はブラウザーのlocalStorageに保存します。

小説テンプレートは `dist/app.js`、肌の項目・尺度は `dist/skin-data.js`、肌テンプレート・比較記録は `dist/skin.js`、共通ナビゲーションは `dist/hub.js` です。肌の入力や比較記録は永続保存せず、上級者ページでJSONの保存・読み込みができます。画像は扱いません。

肌の尺度は、チャット「肌分析に必要な情報を挙げる」の独自の自己観察尺度です。医療的な尺度ではなく、総合点・自己診断には使いません。使用薬・病歴・症状開始日・写真条件の確認についてはAADの受診準備ガイドも参照しています。

ローカルサーバーは `node server.mjs` で起動します（http://127.0.0.1:4187）。

画面は用途選択の後、「レベル選択 → 入力 → プロンプト表示」に分かれます。`dist/flow.js` と `dist/flow.css` が各段階の画面を制御し、URLの `step=level/input/result` とブラウザーの戻る・進むに対応します。入力と出力の往復では同じドキュメント内のメモリーを使って入力と比較記録を保持します。入力内容はURL・履歴state・ストレージに書き込みません。再読込で消去され、出力画面の再読込時は入力画面へ戻ります。
